# ISL Hand Sign Recognizer 👋🇮🇸

A real-time **Indian Sign Language (ISL) hand-sign recognition** pipeline built with
[MediaPipe](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker) hand
landmark detection and a scikit-learn **Random Forest** classifier. Collect your own
training data from a webcam, train a personalized model, and test it live — all from a
single studio app or via standalone scripts.

## Features

- 🎥 **Webcam data collection** with on-screen landmark overlay and hotkey controls
- 🧠 **112-D canonical feature extraction** with chirality locking:
  - Single hands are mirrored to a canonical right-hand representation (100% ambidextrous)
  - Two-hand signs are locked into Left/Right slots — never swapped on crossings/touches
  - Knuckle-based rigid orientation check prevents fist/curl glitches
- 🤖 **Leak-free training**: train/test split happens *before* augmentation
- 📈 **Training-time augmentation** (applied only to training samples):
  - Auto-mirroring for single-hand signs
  - Synthetic Gaussian jitter ("AI safety cushion")
- 🔴 **Zero-lag Linux GUI** (Tkinter popups with X11/Wayland buffer flushing)
- 🔄 **Append mode** to grow existing sign datasets on the fly
- 🎯 Live inference with temporal smoothing and a `Custom_Neutral` idle class

## Project Structure

```
.
├── collect_data.py       # All-in-one studio: record signs, train, and live-test (GUI)
├── train.py              # Standalone trainer — builds my_hand_model.p from dataset/
├── test_live.py          # Standalone live webcam recognizer for a trained model
├── isl_features.py       # 112-D landmark feature extractor + hand skeleton connections
├── hand_landmarker.task  # MediaPipe Hand Landmarker model (bundled)
├── my_hand_model.p       # Trained Random Forest model (generated by train.py)
├── dataset/              # One .pickle file per sign (list of feature vectors)
└── requirements.txt
```

## Installation

Requires Python 3.8+ and a webcam. On Linux you may need Tkinter (`sudo apt install python3-tk`).

```bash
pip install -r requirements.txt
```

Dependencies: `opencv-python`, `mediapipe`, `numpy`, `scikit-learn`.

## Usage

### 1. The Studio (recommended)

```bash
python collect_data.py
```

A startup dialog lets you pick a camera and choose between **recording new signs**,
**training the model in-studio**, and **live testing**. Signs are saved under
`dataset/<SignName>.pickle`; a `Custom_Neutral` sample set (relaxed hands) is captured
automatically to suppress false positives.

Hotkeys during recording/testing: `SPACE` capture/confirm · `R` retake/reset · `Q` quit.

### 2. Train from the command line

With at least two sign files in `dataset/`:

```bash
python train.py
```

This loads every `*.pickle`, splits stratified 80/20, augments the training set, fits a
Random Forest, prints honest held-out accuracy, and saves `my_hand_model.p`.

### 3. Live recognition

```bash
python test_live.py
```

Opens a camera-selection window, then streams real-time predictions with the hand
skeleton drawn over the frame (press `Q` to quit).

## Dataset Format

Each sign is a pickle file containing a list of samples, where every sample is a flat
112-element feature vector produced by `isl_features.extract_features_from_landmarks()`
(52 values per hand slot: wrist + fingertip-relative geometry; the second slot is
zero-filled for single-hand signs).

Bundled example classes include `Alphabet_A` … `Alphabet_Z`, `Number_0/6/8`, and
`Custom_Neutral`.

## How It Works

1. **Detect** — MediaPipe Hand Landmarker extracts 21 3D landmarks per hand each frame.
2. **Normalize & featurize** — `isl_features.py` canonicalizes handedness and produces a
   translation/scale-robust 112-D vector.
3. **Classify** — the Random Forest predicts the sign; live testing applies temporal
   smoothing and maps low-confidence frames to `Custom_Neutral`.

## Tips

- Record 30–50 samples per sign from varied angles/distances for best accuracy.
- Re-run `train.py` after adding new signs — training always uses everything in `dataset/`.
- Delete or rename a `dataset/*.pickle` file to remove a class from the model.
